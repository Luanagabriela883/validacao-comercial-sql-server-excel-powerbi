# **📊 Análise Comercial — Excel, SQL e Power BI**

---

## **🎯 Sobre o Projeto**

Projeto de análise comercial desenvolvido com dados fictícios para praticar análise de dados e gerar insights para o negócio.

## **🛠️ Ferramentas Utilizadas**

- **Excel:** tratamento dos dados e análises.
- **SQL Server:** consultas SQL e análise dos dados.
- **Power BI:** criação de dashboard e visualização de indicadores.

## **🎯 Objetivo**

Analisar o desempenho comercial por meio de indicadores de faturamento, vendas, produtos, clientes, lojas e rentabilidade.

## **❓ Perguntas de Negócio**

1. Qual é o faturamento total e sua evolução mensal?
2. Quais lojas apresentam melhor e pior desempenho?
3. Quais categorias e produtos geram mais receita?
4. Quais produtos apresentam maior lucro e margem?
5. Quais lojas atingiram suas metas mensais?
6. Qual é o ticket médio dos pedidos?
7. Quais clientes e segmentos geram mais receita?
8. Quais formas de pagamento são mais utilizadas?
9. Qual é o impacto dos descontos sobre a receita e o lucro?
10. Quais oportunidades de melhoria comercial os dados revelam?

## **📈 Análises Desenvolvidas**

- Evolução mensal do faturamento.
- Comparação de desempenho entre lojas.
- Análise de receita por categoria e produto.
- Análise de lucro e margem de lucro.
- Acompanhamento de metas mensais.
- Análise de clientes e formas de pagamento.
- Avaliação dos descontos concedidos.

## **📂 Base de Dados**

A base contém dados fictícios de clientes, produtos, lojas, pedidos, itens de pedido e metas mensais.

## **💡 Resultados Esperados**

Identificar oportunidades de melhoria comercial, acompanhar indicadores de desempenho e apoiar decisões baseadas em dados.

## **⚠️ Observação**

Projeto desenvolvido para fins educacionais e de portfólio. Os dados utilizados são fictícios e não representam uma empresa real.
